### Расчёт ROI

#### Год 1
```
Инвестиции: 37,200,000 ₽
Дополнительные затраты: 76,860,000 ₽ (vs AS-IS)
Выгоды: 59,500,000 ₽

Чистый результат: 59,500,000 - 76,860,000 = -17,360,000 ₽
```

#### Год 2
```
Дополнительные затраты: 37,944,000 ₽
Выгоды: 59,500,000 ₽

Чистый результат: 59,500,000 - 37,944,000 = +21,556,000 ₽
Накопленный: -17,360,000 + 21,556,000 = +4,196,000 ₽
```

#### Год 3
```
Дополнительные затраты: 36,142,000 ₽
Выгоды: 59,500,000 ₽

Чистый результат: 59,500,000 - 36,142,000 = +23,358,000 ₽
Накопленный: +4,196,000 + 23,358,000 = +27,554,000 ₽
```

### Итоговый ROI за 3 года

```
Общие инвестиции: 37,200,000 + 150,946,000 = 188,146,000 ₽
Общие выгоды: 59,500,000 × 3 = 178,500,000 ₽

ROI = (178,500,000 - 188,146,000) / 188,146,000 × 100% = -5.1%
```

**Срок окупаемости:** ~2 года (середина 2-го года)

### ROI за 5 лет (прогноз)

```
Год 4: +23,358,000 ₽
Год 5: +23,358,000 ₽

Накопленный за 5 лет: +74,270,000 ₽

ROI за 5 лет = 74,270,000 / 188,146,000 × 100% = +39.5%
```
